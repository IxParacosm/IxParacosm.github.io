# 5. Kit-type schema and tag vocabulary

_Research topic: Transformation-style AI avatar kits and the AI UGC video pipeline: flexible kit-type schema, concrete kit JSON examples, and per-image/clip tag vocabulary_

## Summary

The operator's three generation paths impose different reference-image needs, and the kit schema must express them declaratively. Kling (2.6/3.0, reached via aggregators Atlas Cloud, Poyo and Higgsfield) animates ONE start image per clip (optionally a tail/end image) and can lock identity with 'Elements' (up to 3 reference images per element, up to 3 elements bound in a 3.0 start/end-frame job, referenced in prompts with '@'); its older multi-image endpoint takes 1-4 images. Higgsfield Genjutsu is video-to-video: it keeps the motion, camera and timing of a 4-30s source video and rebuilds the people/scene from up to 30 reference images, which is exactly why the friend's UI says it 'keeps the camera + place' and why it costs ~4-9x a Kling clip (third-party figures: 15s at 480p $2.00, 720p $5.20, 1080p $7.20). HeyGen photo avatars start from a single still (PNG/JPEG, <=32MB, <2K) uploaded to upload.heygen.com/v1/asset, grouped into an Avatar Group with 'looks' generated from it via /v2/photo_avatar/* endpoints; HeyGen recommends 10+ varied photos only when you want many looks, so a 1-3 image 'heygen' kit is correct. Cost signals: Kling 2.6 Pro I2V is $0.07/s without audio and $0.14/s with audio on fal and Atlas; Kling 3.0 Std on Atlas is ~$0.071/s; Poyo lists Kling 3.0 Std around $0.135/generation. Reference-image best practice across Runway, Higgsfield Soul ID and LoRA guides converges on: sharp face, even front light, neutral background, front or 3/4 angle, at least one full-body shot, >=1024px short side, same hair/outfit/makeup across the set, nothing covering the face. Recommended design: a KitType JSON document (image_slots with min/max + required tags, metadata_fields with types, derived assets like the profile photo, ordered process steps, export profiles) stored as data so new types ('transformation', 'heygen', 'custom') are added without code; a single tag vocabulary (phase, framing, angle, movement, camera, place, expression, lighting, outfit) shared by kit images and generated clips so the video builder can filter 'after + full body + turning + gym' the way the friend's tool does. Transformation reels follow hook -> build -> reveal in 6-12s, which maps to before-clips first, cut on a beat/motion change, after-clip as the held reveal. For VA account creation a kit must emit a VA brief: 1024x1024 profile crop from an 'after'/primary image, display name (<=30 chars on both platforms), 2-3 handle candidates (TikTok 2-24 chars; Instagram <=30 chars, letters/numbers/periods/underscores), bio (TikTok 80 chars, Instagram 150), a birthday consistent with the persona age and >=13 years old, plus the email/phone the operator provisions (stored as secret references, never in the Telegram album).

## Gotchas

- Every primary documentation host (fal.ai, kling.ai, higgsfield.ai, heygen.com, docs.heygen.com, atlascloud.ai, poyo.ai, support.tiktok.com, help.instagram.com, runway.com) is blocked by the session egress proxy, so no fact above was read on-page; numbers come from search snippets and should be re-verified from the operator's own accounts before being hard-coded (store prices with an as_of date and a 'live' flag).
- 'Elements' limits differ by Kling generation: the old multi-image endpoint takes 1-4 images total (model default kling-v1-6), while 3.0 binds up to 3 elements with up to 3 reference images each. A kit slot of exactly 6 images (3 before + 3 after) does not map 1:1 onto either; the clip generator must choose which 1-3 images to send per element per job.
- Kling image-to-video animates ONE start image (plus optional tail image); the other kit images only help via Elements or as separate jobs. Do not assume uploading all six yields a consistent character automatically.
- Genjutsu is video-to-video, not image-to-video: it needs a 4-30 s source clip with the motion/camera you want, then rebuilds the person from references. That is why it 'keeps the camera + place' and why its price is per source second at 480p/720p/1080p rather than per generated clip; a transformation kit alone cannot drive it without a motion source video.
- Kling 2.6 with native audio doubles the price ($0.07/s -> $0.14/s on fal and Atlas); the friend's 'Full video - moves + sound' vs 'Moves only' toggle is a 2x cost lever and should be surfaced in the run summary.
- Price figures disagree across sources (Poyo Kling 3.0 Std reported at $0.135/generation by a third party vs the friend's $0.37/clip card; Genjutsu 720p $5.20/15 s from a third-party roundup). Treat all third-party prices as estimates and label them in the UI.
- HeyGen's 'at least 10 photos' guidance is only for generating multiple looks from a trained group; the single-still Avatar IV path is the one that matches the operator's 1-3 image heygen kit. Keep max 2K resolution and 32 MB PNG/JPEG limits in the slot validator (unverified figures).
- HeyGen photo-avatar endpoint names beyond photo/generate, avatar_group/create, look/generate and generation/{id} (e.g. train, add_motion, add_sound_effect) could not be confirmed; mark them provisional in the architecture.
- Persona age/birthday must be internally consistent and >=13 years old on both TikTok and Instagram, otherwise sign-up is refused; store birthday once and derive age at display time.
- Telegram albums cap at 10 items and cannot mix photos and documents; a 6-image kit plus a PDF brief needs two sends. Never put login secrets in the album, since media groups are easy to forward.
- TikTok (80) and Instagram (150) bio limits differ, and TikTok handles max 24 vs Instagram 30; one 'bio' field will break on one platform. Validate per platform at export time.
- Seed control alone gives only mild consistency; reference images give strong consistency; identity drift still occurs with extreme angles or style shifts (Higgsfield's own Soul ID note). Plan a 'review before use' gate on generated images (the friend's 'Her photo: Check it first' toggle).
